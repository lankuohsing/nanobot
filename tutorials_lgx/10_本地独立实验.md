# 10：本地独立实验（CLI / WebUI）

每次实验创建新的 home 和工作区，只复制固定配置与角色。旧问答、记忆和结果保留在旧目录，下次不复用。以下步骤使用原生 nanobot 命令。

如果只需分开对话、记忆与任务目录，也可以固定 home、每次更换全新的 Agent 工作区；上传、缓存等仍共享，简洁操作见 [第 11 章](./11_固定配置切换工作区.md)，原理见 [第 09 章](./09_独立定时任务与状态隔离.md#固定-home只更换-agent-工作区)。

## 1. 准备一次

```bash
conda activate py312
cd /Users/guoxing.lan/projects/github/nanobot
```

当前固定模板已放在 `tutorials_lgx/.runtime/task_template/`：`config.json` 保存公司 API 与模型参数，`workspace/` 保存固定的 `AGENTS.md`、`SOUL.md`、`USER.md`。以后改模型或角色，修改模板；不要把旧记忆、会话和报告放进模板。新同事的模型配置方法见 [第 03 章](./03_公司模型接口配置.md)。

首次使用前，手动在模板 `config.json` 中设置以下字段，保留原有公司模型配置：

| 配置项 | 值 | 作用 |
| --- | --- | --- |
| `agents.defaults.dream.enabled` | `false` | 关闭后台记忆整理 |
| `gateway.heartbeat.enabled` | `false` | 关闭后台心跳任务 |
| `tools.restrictToWorkspace` | `true` | 文件操作限定在本次工作区 |
| `tools.exec.enable` | `false` | 暂停 shell，避免跨目录读写；需要代码执行时再配置沙箱 |
| `tools.cliApps.enable` | `false` | 暂停可访问外部状态的 CLI Apps |

模板保持没有启用的其他聊天通道或 MCP。当前模板只保存模型与固定角色，上表设置需要手动确认和补充一次，再用于后续复制。

## 2. 每次实验先创建新目录

每次都完整执行这段命令，`uuidgen` 会生成新的目录名：

```bash
LGX_TASK_HOME="$PWD/tutorials_lgx/.runtime/manual_runs/$(uuidgen)"
mkdir -p "$LGX_TASK_HOME/workspace"
cp tutorials_lgx/.runtime/task_template/config.json "$LGX_TASK_HOME/config.json"
cp tutorials_lgx/.runtime/task_template/workspace/{AGENTS.md,SOUL.md,USER.md} "$LGX_TASK_HOME/workspace/"
echo "$LGX_TASK_HOME"
```

将本次数据放入打印目录的 `workspace/`，让 Agent 把报告也写在这里。配置、角色是模板的副本，本次修改不会改回模板。整个 `.runtime/` 已被 Git 忽略。准备完成后，第 3、4 节任选一种运行方式。

## 3. CLI：发送本次任务

```bash
python -m nanobot --home "$LGX_TASK_HOME" agent \
  --workspace "$LGX_TASK_HOME/workspace" \
  -m "替换为本次任务描述与数据；报告写在当前工作区。"
```

会调用公司模型，回复后本次 CLI 进程结束。会话记录保存到本次 home；新 home 没有旧历史，可以使用默认 session，不需要每次 onboard。

## 4. WebUI：启动本次实验

CLI 和 WebUI 按需要选择。启动前检查两个端口：

```bash
lsof -nP -iTCP:8767 -iTCP:18793 -sTCP:LISTEN
```

有输出时先停止端口所属服务，或换两个空闲端口；都空闲后启动：

```bash
python -m nanobot --home "$LGX_TASK_HOME" webui \
  --workspace "$LGX_TASK_HOME/workspace" \
  --yes --no-dock --port 8767 --gateway-port 18793
```

网页入口：[http://127.0.0.1:8767](http://127.0.0.1:8767)。使用本次默认工作区，保持 Restricted 权限，新建普通话题并提交本次任务；同一实例只做这一项实验。

完成后回到终端按 `Ctrl+C`，再明确停止本次网关：

```bash
python -m nanobot --home "$LGX_TASK_HOME" gateway stop \
  --workspace "$LGX_TASK_HOME/workspace"
```

## 5. 下一次怎么做

重新执行第 2 节，再选择 CLI 或 WebUI。不要沿用旧的 `LGX_TASK_HOME`，也不要用 `--config` 指回旧配置；显式的 `--workspace` 确保不会误用配置中的旧工作区路径。无需删除旧记录或清空 memory。

目录隔离覆盖本地会话、记忆和任务文件；共享数据库、外部账户需要业务工具另行约束。命令依据当前源码核对，本文未启动实际任务或调用模型。
