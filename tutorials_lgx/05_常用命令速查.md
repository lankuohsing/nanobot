# 05：日常实验命令速查

适用于当前 `py312` 学习实例；安装、初始化和模型配置见 [02](./02_首次运行.md)、[03](./03_公司模型接口配置.md)。每次打开新终端，先执行第 1 节。

## 1. 准备终端

```bash
conda activate py312
cd /Users/guoxing.lan/projects/github/nanobot
export LGX_NANOBOT_HOME="$PWD/tutorials_lgx/.runtime"
```

## 2. 启动与停止 WebUI

```bash
python -m nanobot --home "$LGX_NANOBOT_HOME" webui \
  --yes --port 8766 --gateway-port 18791
```

浏览器入口：[http://127.0.0.1:8766](http://127.0.0.1:8766)。保持启动终端打开，`Ctrl+C` 退出启动器；需要明确停止该实例网关时，在另一个已按第 1 节准备的终端执行：

```bash
python -m nanobot --home "$LGX_NANOBOT_HOME" gateway stop
```

修改配置或 Python 源码后，停止并重新启动以加载改动。配置文件为 `tutorials_lgx/.runtime/config.json`。

## 3. 命令行发送一条消息

```bash
# 会调用已配置的模型；把消息替换为本次实验输入
python -m nanobot --home "$LGX_NANOBOT_HOME" agent \
  --session lgx:debug -m "只回复：连接成功。"
```

同一 `--session` 保留对话历史；不同实验可更换名称，但同一实例仍共享长期记忆。

## 4. 检查与排查

```bash
# 检查配置，不调用模型
python -m nanobot --home "$LGX_NANOBOT_HOME" status

# 查看网关是否运行
python -m nanobot --home "$LGX_NANOBOT_HOME" gateway status

# 查看版本、检查环境依赖
python -m nanobot --version
python -m pip check

# 查询 WebUI 参数
python -m nanobot webui --help
```

运行或管理实例时保留 `--home`；版本、帮助和 pip 操作不需要它。新同事替换第 1 节的环境名与仓库路径；使用模型环境变量引用时，还需按 [03](./03_公司模型接口配置.md#3-可选使用环境变量引用) 设置变量。
