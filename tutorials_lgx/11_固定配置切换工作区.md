# 11：固定配置，每次切换新工作区

适用于串行的本地调试：公司 API 配置保持一份，每次实验使用全新的 Agent 工作区，分开问答历史、长期记忆和任务文件。无需每次创建新 home、onboard 或清空旧记录，也不必先关闭长期记忆。

## 1. 准备一次

先完成源码安装和[公司 API 配置](./03_公司模型接口配置.md)。以下路径和环境名是作者本机示例，同事替换为自己的值；命令从仓库根目录执行：

```bash
conda activate py312
cd /Users/guoxing.lan/projects/github/nanobot
export LGX_NANOBOT_HOME="$PWD/tutorials_lgx/.runtime"
```

后续一直复用 `$LGX_NANOBOT_HOME/config.json`。不需要后台活动时，可手动设置 `agents.defaults.dream.enabled=false` 和 `gateway.heartbeat.enabled=false`；前者只停止后台记忆整理。

若原学习 WebUI 仍在运行，先在启动终端按 `Ctrl+C`，再停止其 Gateway。原启动命令没有 `--workspace` 时执行：

```bash
python -m nanobot --home "$LGX_NANOBOT_HOME" gateway stop
```

若原启动命令带了 `--workspace`，停止时也要带原来的工作区路径。

## 2. 每次实验创建新工作区

每次都重新执行，`uuidgen` 保证目录名不同。使用 WebUI 时，先按第 4 节停止上次服务，再执行本步。

```bash
LGX_TASK_WORKSPACE="$LGX_NANOBOT_HOME/experiments/$(uuidgen)"
mkdir -p "$LGX_TASK_WORKSPACE"
echo "$LGX_TASK_WORKSPACE"
```

把本次数据放入打印出的目录。启动时 nanobot 会补齐默认角色文件；若需要自定义金融角色，启动前仅复制干净模板中的 `AGENTS.md`、`SOUL.md`、`USER.md` 和必要的 `skills/`。不要复制旧 `memory/`、`.nanobot/` 或历史报告。

## 3. CLI：运行一次任务

```bash
python -m nanobot --home "$LGX_NANOBOT_HOME" agent \
  --workspace "$LGX_TASK_WORKSPACE" \
  -m "替换为本次任务描述；使用当前工作区的数据，报告也写在当前工作区。"
```

收到回复后进程结束。下次重新执行第 2、3 步；可以使用默认 session，新工作区的历史独立。CLI 的 `--workspace` 只影响本次运行，不修改配置文件。

## 4. WebUI：运行一次任务

第 3、4 节任选一种。确认 `8767`、`18793` 两个端口空闲后启动，端口检查见[常用命令速查](./05_常用命令速查.md#5-检查与排查)：

```bash
python -m nanobot --home "$LGX_NANOBOT_HOME" webui \
  --workspace "$LGX_TASK_WORKSPACE" \
  --yes --no-dock --port 8767 --gateway-port 18793
```

打开 [http://127.0.0.1:8767](http://127.0.0.1:8767)，保持本次默认工作区与 Restricted 权限，新建普通话题，提交本次任务。网页里的“项目选择”不等同于切换全局 Agent 工作区。

完成后在启动终端按 `Ctrl+C`，再执行：

```bash
python -m nanobot --home "$LGX_NANOBOT_HOME" gateway stop \
  --workspace "$LGX_TASK_WORKSPACE"
```

确认服务停止后，下次重新执行第 2、4 步。停止前不要更改 `LGX_TASK_WORKSPACE`。WebUI 的 `--workspace` 会保存到配置中，运行中手改配置不会立即切换 Agent。

## 5. 记住这几点

- 固定 home 保存 API 配置；全新 workspace 分开长期记忆、任务文件和按工作区 ID 分区的会话历史。会话数据库仍位于 `home/sessions/<workspace-id>/sessions.sqlite3`。
- home 下的上传、缓存、认证、日志等仍共享；旧上传不会自动进入上下文，但文件工具仍可读取共享的 `home/media/`。此方案不保证工具无法访问其他目录。
- 若要求上传和实例状态的目录也分开，使用[第 10 章：每次新建 home](./10_本地独立实验.md)。隔离原理与工具边界见[第 09 章](./09_独立定时任务与状态隔离.md#固定-home只更换-agent-工作区)。

命令依据当前源码核对；本文未启动服务或调用模型。实际运行任务会调用已配置的公司 API。
